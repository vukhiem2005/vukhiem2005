[**ÉLAN — AI Fashion Recommender**](https://github.com/vukhiem2005/ai-fashion-recommender)

AI-powered fashion storefront featuring **CLIP Late Fusion** for multimodal product similarity, **ItemKNN** for synthetic shopper personalization, and **TF-IDF** fallback. Built with Next.js, FastAPI, and SQLite.

[Live Demo](https://elan-fashion-store.vercel.app/) · [Source Code](https://github.com/vukhiem2005/ai-fashion-recommender)
